# Succubi Server v1.1.0: รีโนเวททั้งแอดออน + แยกปืนเป็นแพ็คของตัวเอง

ไฟล์ติดตั้ง: **`Succubi_Server_v1.1.0.mcaddon`** (28.2 MB) สร้างจาก `Succubi_Server_v1.0.19.mcaddon` ด้วย `tools/v20/build.py`

## ในไฟล์มี 5 แพ็ค
| แพ็ค | ทำอะไร | ถอดได้ไหม |
|---|---|---|
| **Succubi Server BP / RP** | กระเป๋าเงิน ร้านค้า HUD ส่วนสูง การแพทย์ หิวน้ำ ค่าสติ เรื่องสยอง | แพ็คหลัก |
| **Succubi Guns BP / RP** (ใหม่) | ปืน เกราะ ระเบิด ของตกแต่งทหาร (Aplok Guns) | **ถอดออกได้ทุกเมื่อ** แพ็คหลักยังทำงานครบ |
| **Succubi Server Link BP** | ส่งค่าความหิวให้ HUD | เปิดตามแพ็คหลักเอง |

### อัปเดตโลกเดิมจาก v1.0.x
1. นำเข้า `.mcaddon` ใหม่ (แพ็คหลัก UUID เดิม จึงอัปเดตทับของเดิมได้เลย)
2. ถ้ายังอยากมีปืน: ตั้งค่าโลก → Behavior Packs → เปิด **Succubi Guns BP** (RP เปิดตามเอง)
3. **ลำดับแพ็ค: Succubi Guns BP ต้องอยู่เหนือ Succubi Server BP** เพราะทั้งสองแพ็คมี player.json ถ้าวางผิดลำดับ แอดมินจะเห็นข้อความเตือนในแชตตอนเข้าโลก
4. ถอดปืนภายหลัง: ปิด Succubi Guns BP/RP ได้เลย ไม่มีอะไรพัง (ปืนที่อยู่ในกระเป๋าจะหายไปตามปกติของไอเทมที่ไม่มีแพ็ค)

## สิ่งที่แก้
- **เอาระบบเข็มทิศออก** ไม่มีเมนูเข็มทิศ คำสั่ง `!menu` และของแจกฟรีแล้ว (เดิมกดเบิกชุดชุบชีวิต 590 บาทได้ฟรีไม่จำกัด)
  - ปุ่มที่ 4 ในกระเป๋าตังค์เปลี่ยนเป็น **ตั้งค่า** ใช้ ซ่อน/แสดง HUD, ปรับส่วนสูง และดูวิธีใช้ปืน (ขึ้นเฉพาะตอนเปิดแพ็คปืน)
  - ปิดกระเป๋าด้วยปุ่ม X ที่มุม
- **ร้านค้าเก็บได้เฉพาะเจ้าของหรือแอดมิน** คนที่วางร้านเป็นเจ้าของ คนอื่นย่อ+คลิกขวาแล้วจะขึ้นชื่อเจ้าของ ร้านที่วางก่อน v1.1.0 ไม่มีเจ้าของ จึงเก็บได้เฉพาะแอดมิน
- **player.json ไม่ซ้ำแล้ว** แต่ละแพ็คมีไฟล์เดียว และเอา subpack ออก
  - ชื่อผู้เล่นตั้งในไอเทมตั้งค่าเซิร์ฟ: "แสดงตลอด" หรือ "เห็นเมื่อมองตรงๆ" (แทน subpack No Nametag เปลี่ยนได้ทันทีโดยไม่ต้องโหลดแพ็คใหม่)
- **ส่วนสูงยุติธรรม**
  - ผู้เล่นปรับได้ 140–220 ซม. (เลือด 60–140)
  - ปุ่ม +/- แค่ขยับตัวอย่าง ต้องกด **ยืนยัน** ถึงจะมีผล
  - เปลี่ยนได้ครั้งละ 5 นาที และห้ามเปลี่ยนภายใน 15 วินาทีหลังโดนตี/ตีคนอื่น
  - แอดมิน หรือเมื่อเปิดสวิตช์ "ส่วนสูงอิสระ" ในไอเทมตั้งค่า ได้ 1–500 ซม. เหมือนเดิม
  - คนที่สูงเกินช่วงจะถูกปรับเข้าช่วงตอนเกิดใหม่
- **HUD ไม่ทับ /title แล้ว**
  - ข้อมูล HUD ถูกเก็บไว้ในหน้าจอ สคริปต์เลยส่งเฉพาะตอนค่าเปลี่ยน (เดิมส่งทุก 2 วินาที)
  - ถ้าจะโชว์ /title ยาวๆ ในแมพ ให้สั่ง `/scriptevent succubi:hud_pause 10` ก่อน (ถ้าผู้เล่นสั่ง จะพักเฉพาะคนนั้น ถ้า command block สั่ง จะพักทุกคน)
- **เวอร์ชันตรงกันทุกที่** (1.1.0) และ `min_engine_version` เป็น 1.21.90 ทุกแพ็ค

## รีโนเวทหน้าตา
- **เอาโลโก้ "APLOK GUNS"** ที่แทนโลโก้ Minecraft ออก และเอาเลขเวอร์ชัน v1.1.8 ที่มุมจอออก
- **HUD ใหม่ทั้งหมด** (`previews/v110_hud.png`)
  - แถบพิกเซลอาร์ต 2 แถวแทนที่หัวใจ/น่องไก่เดิม: เลือด (มีตัวเลข, เขียวตอนติดพิษ, ดำตอน wither) | อาหาร / น้ำ | สติ
  - ป้ายเกราะ (แสดงค่าเกราะรวม) ขึ้นเฉพาะตอนใส่เกราะ
  - ค่าไหนต่ำ ไอคอนจะเรืองแสงกะพริบ
  - ระบบที่แอดมินปิด (น้ำ/สติ) แถบนั้นจะหายไป
  - ซ่อนเองในครีเอทีฟ/สเปกเตเตอร์ หรือเมื่อกด F1
- **ฟอนต์**: ทุกหน้าจอของเซิร์ฟใช้ฟอนต์ smooth ของเกม (สระและวรรณยุกต์ไทยวางตำแหน่งถูก คมทุกขนาด)
  - ชื่อไอเทมและแชตยังเป็นฟอนต์ปกติของเกม
- **หน้าต่างธีม Succubi** (`previews/v110_screens.png`)
  - พื้นพลัมเข้ม ตราค้างคาว ปุ่มแบบการ์ด
  - สีเน้นแยกตามประเภท: ชมพู = ผู้เล่น, ทอง = ตั้งค่าแอดมิน, แดงเลือด = อุปกรณ์กฎสยอง
- **หน้าปรับส่วนสูงใหม่**: ไม้บรรทัด 0–250 ซม. (แอดมิน 0–500), หุ่นเทียบ 180 ซม., ปุ่ม +/- ค้างคาวจากชุดไอคอนใน repo
- **ไอคอนใหม่ 21 ชิ้น** (`previews/v110_icons.png`)
  - เครื่องราง 14 ชิ้น, กระดิ่งเรียกผี, ไม้เท้ากฎสยอง, อุปกรณ์ตั้งค่า (เฟืองค้างคาว), เครื่องมือปรับส่วนสูง, ผ้าพันแผล, ชุดชุบชีวิต, เข็มฉีด
  - การ์ดในร้านที่มีของพวกนี้อัปเดตรูปแล้ว
- **โมเดลใหม่ 8 ชิ้น** (`previews/v110_models.png`)
  - เดิมเป็นกล่องสี่เหลี่ยมซ้อนกัน: ซาลาเปา, ไข่ต้ม, ข้าวปั้นแซลมอน/ทูน่า, แซนด์วิชแฮม, ขนมจีบในเข่งไม้ไผ่
  - รูปปั้นเฝ้ามองกลายเป็นรูปปั้นเทวดาหินมีปีก
  - เงาดำเป็นร่างสูงผอม ตาแดง ชายผ้าขาดรุ่ย
  - ไอคอนเรนเดอร์จากโมเดลใหม่
- **ไอคอนแพ็คปืน** ใหม่ (เป้าเล็งชมพู + ค้างคาว)

## Build
```bash
pip install pillow numpy
python3 tools/v20/build.py Succubi_Server_v1.0.19.mcaddon /tmp/succubi_work Succubi_Server_v1.1.0.mcaddon
```
- `overlay/` = สคริปต์ที่แก้มือ (วางทับหลังแยกแพ็ค)
- `tools/v20/`
  - `split.py` แยกแพ็คโดยตามการอ้างอิงของไฟล์
  - `packs.py` สร้าง manifest, player.json 2 แบบ และตารางค่าเกราะ
  - `art_hud.py` HUD, `art_ui.py` หน้าต่าง/ฟอนต์/หน้าส่วนสูง, `art_icons.py` ไอคอน, `art_models.py` โมเดล
  - `validate.py` ตรวจว่าทุกแพ็คใช้ได้ด้วยตัวเอง (build ไม่ผ่านถ้ามีไฟล์ที่อ้างถึงหายไป)
- ภาพพรีวิว: `preview_hud.py` และ `preview_ui.py` (อ่าน JSON UI จริงแล้ววาดออกมา)
- เทสต์สคริปต์ใน Node: `tools/v20/jstest/` (`setup.sh <scripts> <dir>` แล้ว `node test_core.mjs`)
- `art/` = ชุดไอคอนค้างคาว (ปุ่ม +/−, ย้อนกลับ, เฟือง ฯลฯ) ที่ใช้ในหน้าจอ

# Succubi Server — ร้านค้าซุ้มอาหาร อาหาร 3D แผงขายยา และร้านสะดวกซื้อ

ไฟล์ติดตั้งล่าสุด: **`Succubi_Server_v1.0.19.mcaddon`** (รอบแรกคือ v1.0.11: Succubi_Server_v1.0.10 + kiosk_shops_pack + Food_Items_v1.0.4 รวมเป็นแอดออนเดียว)

> ⚠️ **ถอด `Kiosk Shops` และ `Food & Drinks 3D` ตัวเก่าออกจากโลกก่อน** เพราะของในแพ็คนี้ใช้ ID เดิม (`kiosk:*`, `food:*`)
> ซุ้มที่วางไว้แล้วกับอาหารที่มีอยู่ในโลกจะยังอยู่ครบ และซุ้มเก่าจะกลายเป็นร้านที่ขายของได้ทันที

## มีอะไรใหม่
- **คลิกขวาที่ซุ้ม = เปิดร้าน** ใช้ระบบเดียวกับตู้กดน้ำ คือใส่เงินสด (เหรียญ/แบงก์) แล้วกดซื้อ ปิดหน้าร้านแล้วร้านทอนเงินให้เอง
  - ร้านรับแบงก์ 500 และ 1000 ด้วย (ของบางอย่างราคาเกิน 100 บาท)
  - **ย่อ + คลิกขวา = รื้อซุ้ม** เหมือนเดิม และซุ้มจะไม่เปิดเป็นกล่องเก็บของ 27 ช่องอีกแล้ว
- **HUD แยกของแต่ละร้าน** ใช้เลย์เอาต์เดียวกับตู้กดน้ำ แต่เปลี่ยนสีและลายตามร้าน (ดู `previews/shop_screens.png`)
- **อาหารใหม่ 19 เมนู** ใช้โมเดล 3D จาก Food Items มีเมนูทำใหม่ด้วยการเปลี่ยนสีเท็กซ์เจอร์ เช่น ชาไทย มัทฉะ โกโก้ ราเมงต้มยำ ราเมงทงคตสึ ไก่ซอสเกาหลี ส้มตำปูปลาร้า และแมลงผงต้มยำ
  - ของเผ็ดหรือเค็มจะทำให้ **กระหายน้ำเพิ่ม** ส่วนของที่เป็นซุปหรือเครื่องดื่มช่วยดับกระหาย ทุกเมนูบอกผลไว้ในคำอธิบายไอเทม (lore)
- **แก้ท่ากินให้ถูกด้าน** ทั้งอาหารใหม่ และน้ำ/ขนม 22 อย่างจากตู้เดิม:
  - ตอนถือ: อาหารตั้งตรง จานวางราบบนมือ
  - ตอนกิน: จานเอียงหาปาก แก้ว/ขวดหันปากขวดเข้าหาปาก
  - มุมมองบุคคลที่ 1 กับบุคคลที่ 3 ใช้ท่าแยกกัน (ดู `previews/food_poses_*.png`)
- **หมวดในครีเอทีฟ (แท็บอุปกรณ์/สวมใส่)**
  - กลุ่ม **อาหารและเครื่องดื่ม**: อาหารทั้งหมด
  - กลุ่มใหม่ **ร้านค้า**: ซุ้ม 6 ร้าน + ตู้กดน้ำ + ตู้ขนม (ตู้เปลี่ยนจากไข่ spawn เป็นไอเทมวางได้เลย)

### 4. เซอร์ไพรส์: คืนพระจันทร์เลือด
- ทุกคืนมีโอกาส 1 ใน 7 ที่จะเป็นคืนพระจันทร์เลือด: หมอกแดงทั้งคืนสำหรับทุกคน เรื่องแปลกเกิดเร็วขึ้น 6 เท่า สติลดช้าๆ (−1.5/นาที) จบเองตอนพระอาทิตย์ขึ้น
- มีข้อความเตือนทุกคนตอนเริ่มและตอนจบ เปิด/ปิด หรือสั่งเริ่มทันที (เปลี่ยนเวลาเป็นกลางคืน) ได้ที่อุปกรณ์ตั้งค่า
- เครื่องราง/หนังสือช่วยรับมือได้: ยันต์กันผีลดความถี่ครึ่งหนึ่ง, หนังสือสวดมนต์กันเรื่องแปลกครั้งถัดไป, หนังสือธรรมะกันคำสาปตุ๊กตา

### 5. อุปกรณ์กฎสยอง (Rule of Horror) — กลุ่มใหม่ในครีเอทีฟ ใช้ได้เฉพาะแอดมิน (โหมดสร้างสรรค์หรือแท็ก `succubi_admin`)
- **ไม้เท้ากฎสยอง**: คลิกขวา → สร้างโซนกฎตรงที่ยืน ตั้งชื่อ, กฎ, รัศมี 2–40 บล็อก, บทลงโทษ, ช่วงเวลา (ตลอด/กลางคืน/กลางวัน), ข้อความตอนเข้าโซนและตอนทำผิด · ดู/แก้/ย้าย/วาร์ป/ลบโซนใกล้ตัว · ถือไม้เท้าไว้จะเห็นขอบโซนเป็นเปลวไฟ
  - กฎ 16 แบบ: ห้ามวิ่ง, ห้ามกระโดด, ต้องย่อตลอด, ห้ามย่อ, ห้ามขยับ, ห้ามถือแสงไฟ, ห้ามถืออาวุธ, ห้ามกิน/ดื่ม, ห้ามวาง/ทุบบล็อก, ห้ามเปิดประตู, ห้ามอยู่เกินเวลา, ห้ามมองขึ้นฟ้า, ห้ามก้มมองพื้น, ห้ามอยู่คนเดียว, ห้ามเข้า, ห้ามพิมพ์แชต (ต้องเปิด Beta APIs)
  - บทลงโทษ 9 แบบ: ลดสติ 10 / 25, เรื่องแปลกสุ่ม, ผีโผล่ตรงหน้า (jumpscare), ดาเมจ 4, ผลักออกนอกโซน, หมอกแดง 30 วิ, ส่งกลับจุดเกิดโลก, ตายทันที
  - ผู้เล่นโหมดสร้างสรรค์/สเปกเตเตอร์ไม่โดนกฎ
- **ป้ายประกาศกฎ**: วางไว้ให้คนคลิกขวาอ่าน (หน้าจอกระดาษ) แอดมินถือไม้เท้าแล้วคลิกขวาที่ป้ายเพื่อเขียนหัวข้อ + กฎ 8 ข้อ
- **รูปปั้นเฝ้ามอง**: ขยับเข้าหาผู้เล่นในระยะ 24 บล็อกเฉพาะตอนไม่มีใครมองมัน ถ้าถึงตัว = ผีโผล่ + ดาเมจ 6 + สติ −20 แล้วรูปปั้นกลับที่เดิม · แอดมินถือไม้เท้าคลิกขวาเพื่อเปิด/ปิด
- **ลำโพงหลอน**: เล่นเสียงหลอน 14 แบบให้คนรอบๆ ทุก 10–300 วินาที ระยะ 8–32 บล็อก ลดสติได้ 0–5 ต่อครั้ง (แอดมินคลิกขวาเพื่อตั้งค่า)
- **กระดิ่งเรียกผี**: แอดมินสั่น → ทุกคนใน 48 บล็อกได้ยิน สติ −3 และ 25% เจอเรื่องแปลก (คนทั่วไปสั่นได้แค่มีเสียง)
- เก็บของที่วางไว้: แอดมินย่อ + คลิกขวา · ปิดทั้งชุดได้ที่อุปกรณ์ตั้งค่า (อุปกรณ์กฎสยอง)

unzip Succubi_Server_v1.0.10.mcaddon -d server
unzip Food_Items_v1.0.4.mcaddon -d food
unzip kiosk_shops_pack.zip -d kiosk
pip install pillow numpy imageio-ffmpeg
python3 tools/build.py server out Succubi_Server_v1.0.19.mcaddon
python3 tools/verify_out.py   # เรนเดอร์ท่าถือ/ท่ากินทุกเมนูไว้ที่ view/
