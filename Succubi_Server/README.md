# Succubi Server — ร้านค้าซุ้มอาหาร อาหาร 3D แผงขายยา และร้านสะดวกซื้อ

ไฟล์ติดตั้งล่าสุด: **`Succubi_Server_v1.0.12.mcaddon`** (รอบแรกคือ v1.0.11: Succubi_Server_v1.0.10 + kiosk_shops_pack + Food_Items_v1.0.4 รวมเป็นแอดออนเดียว)

> ⚠️ **ถอด `Kiosk Shops` และ `Food & Drinks 3D` ตัวเก่าออกจากโลกก่อน** เพราะของในแพ็คนี้ใช้ ID เดิม (`kiosk:*`, `food:*`)
> ซุ้มที่วางไว้แล้วกับอาหารที่มีอยู่ในโลกจะยังอยู่ครบ และซุ้มเก่าจะกลายเป็นร้านที่ขายของได้ทันที

## มีอะไรใหม่
- **คลิกขวาที่ซุ้ม = เปิดร้าน** ใช้ระบบเดียวกับตู้กดน้ำ คือใส่เงินสด (เหรียญ/แบงก์) แล้วกดซื้อ ปิดหน้าร้านแล้วร้านทอนเงินให้เอง
  - ร้านรับแบงก์ 500 และ 1000 ด้วย (ของบางอย่างราคาเกิน 100 บาท)
  - **ย่อ + คลิกขวา = รื้อซุ้ม** เหมือนเดิม และซุ้มจะไม่เปิดเป็นกล่องเก็บของ 27 ช่องอีกแล้ว
- **HUD แยกของแต่ละร้าน** ใช้เลย์เอาต์เดียวกับตู้กดน้ำ แต่เปลี่ยนสีและลายตามร้าน (ดู `previews/shop_screens.png`)
- **อาหารใหม่ 19 เมนู** ใช้โมเดล 3D จาก Food Items มีเมนูทำใหม่ด้วยการเปลี่ยนสีเท็กซ์เจอร์ เช่น ชาไทย มัทฉะ โกโก้ ราเมงต้มยำ ราเมงทงคตสึ ไก่ซอสเกาหลี ส้มตำปูปลาร้า และแมลงผงต้มยำ
  - ของเผ็ดหรือเค็มจะทำให้ **กระหายน้ำเพิ่ม** ส่วนของที่เป็นซุปหรือเครื่องดื่มช่วยดับกระหาย ทุกเมนูบอกผลไว้ในคำอธิบายไอเทม (lore)
- **แก้ท่ากินให้ถูกด้าน** ทั้งอาหารใหม่ และน้ำ/ขนม 22 อย่างจากตู้เดิม:
  - ตอนถือ: อาหารตั้งตรง จานวางราบบนมือ
  - ตอนกิน: จานเอียงหาปาก แก้ว/ขวดหันปากขวดเข้าหาปาก
  - มุมมองบุคคลที่ 1 กับบุคคลที่ 3 ใช้ท่าแยกกัน (ดู `previews/food_poses_*.png`)
- **หมวดในครีเอทีฟ (แท็บอุปกรณ์/สวมใส่)**
  - กลุ่ม **อาหารและเครื่องดื่ม**: อาหารทั้งหมด
  - กลุ่มใหม่ **ร้านค้า**: ซุ้ม 6 ร้าน + ตู้กดน้ำ + ตู้ขนม (ตู้เปลี่ยนจากไข่ spawn เป็นไอเทมวางได้เลย)

## v1.0.12 — แผงขายยา + ร้านสะดวกซื้อ

ไฟล์ติดตั้ง: **`Succubi_Server_v1.0.12.mcaddon`** (26.8 MB) มีทุกอย่างของ v1.0.11 อยู่ด้วยแล้ว

- **ของวางใหม่ 4 ชิ้น** (กลุ่ม **ร้านค้า**): แผงขายยา, ชั้นวางขนม, ตู้แช่เครื่องดื่ม, เคาน์เตอร์อาหารพร้อมทาน
  - โมเดลสร้างด้วยโค้ดเป็นทรงกล่อง ลายและป้ายภาษาไทยวาดด้วยสคริปต์ ใช้โทนสีแบบร้านสะดวกซื้อแต่ไม่มีโลโก้ยี่ห้อจริง (ดู `previews/store_stands.png`)
  - วางแล้วหันหน้าเข้าหาคนวาง, คลิกขวา = เปิดร้าน, ย่อ + คลิกขวา = เก็บคืนเป็นไอเทม
- **หน้าร้านแบบ 6 แถว** (ของขายได้สูงสุด 14 อย่างต่อร้าน) ธีมเขียวสำหรับร้านยา และขาว-ส้ม-เขียว-แดงสำหรับร้านสะดวกซื้อ (ดู `previews/shop_screens_store.png`)
- **ของใหม่ 24 อย่าง**: ยา 9, ขนม 3, เครื่องดื่ม 2, อาหารพร้อมทาน 10 (ดู `previews/store_items.png`) ถือและกินแบบเดียวกับอาหารรอบก่อน
- **ยาทำงานได้จริง**: ฟื้นเลือดทันที, ให้เอฟเฟกต์ และล้างอาการแย่ (พิษ คลื่นไส้ อ่อนแรง ฯลฯ) ตามที่เขียนไว้ในคำอธิบายไอเทม
